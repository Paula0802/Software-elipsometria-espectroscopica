Flujo de trabajo
📂
Cargar espectro
Importa tu archivo CSV, SPE, TXT o XLSX con los ángulos Ψ(λ) y Δ(λ) medidos.
🧱
Definir modelo
Construye la estructura multicapa y elige el modelo de dispersión para cada capa.
⚙️
Optimizar
Ejecuta Levenberg–Marquardt o Simplex Nelder-Mead para ajustar los parámetros.
📈
Analizar
Visualiza n(λ), k(λ) y compara el espectro teórico contra el experimental.
Módulos del software
Modelado óptico (TMM)
Calcula la respuesta elipsométrica teórica de estructuras multicapa mediante el método de la matriz de transferencia.
TMM multicapa
Modelos de dispersión
Cauchy, Sellmeier, Drude, Lorentz, Lorentz-Drude y teorias de medio efectivo para modelar índices ópticos en el rango visible-NIR.
Cauchy Sellmeier Drude-Lorentz
Optimización
Dos algoritmos complementarios: Levenberg–Marquardt para convergencia rápida y Simplex Nelder-Mead para búsqueda global robusta.
L–M Nelder-Mead
